# About the runtime

The case studies and results in this repo come from CEM888, a personal,
long-running multi-agent runtime — model-agnostic orchestration, persistent
state and memory, scheduled/background agents, and a self-maintaining
skill system, operated continuously in production rather than as a demo.
Evidence is drawn from multiple independently-running agent instances on
this runtime (referred to as "Ember" and "Vetta" in the case studies) —
same underlying system, separate deployments, separate telemetry.

**The runtime's implementation is proprietary and is not published here.**
No source code, prompts, agent configuration, orchestration or
context-selection logic, memory/retrieval implementation, or tool-routing
implementation is included in this repository or anywhere public.
Credentials, internal identifiers (session/call/room IDs, hostnames, IP
addresses, ticket numbers, internal file paths), and raw logs or
transcripts are never included — every number published here was extracted
from that material and reported on its own, with the source scrubbed.

What *is* public is the evidence: real interventions, real dates, real
outcomes, written up in [`case-studies/`](case-studies/) and
[`results/`](results/) using the fixed template in
[`methodology.md`](methodology.md).
